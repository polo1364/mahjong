# 青禾麻將：台灣 16 張含花牌規則

版本：`tw16-flowers-v1`，2026-10-20。

台灣各地牌桌有差異；本桌採以下固定版本，畫面、引擎及測試均以此為準。不是特定賽事的認證規章。

## 牌組與行牌

- 144 張：萬、筒、索各 36 張，字牌 28 張，春夏秋冬、梅蘭竹菊各一張。
- 起手莊家 17 張、閒家 16 張。一般胡牌必須五面子一對將；槓按一面子算，實體多出的一張不算手牌缺額。不採八對子、七對子或十三么。
- 起手花先亮出，再由莊家起依座次補花；摸到花立即亮出，從牌尾補到一般牌為止。花牌不進手牌、不組面子、不打入棄牌區。
- 海底固定保留 16 張；每次補牌從保留區尾端取一張，再由可摸牌山尾端補回一張。可摸牌用完就流局；末張花不能動用保留牌補花，但仍可觸發下述花胡。
- 逆時針行牌。只吃上家，胡優先於碰槓，碰槓優先於吃；多人同時可胡時只取離出牌者最近的一家。
- 上家的棄牌不可明槓；吃碰後必須出牌，不能接著槓。明槓補牌不可自摸；暗槓、加槓及一般摸花補牌可以自摸。
- 吃牌後不能打出被吃的牌或同絡另一端，例如 34 吃 2，不能打 2、5；碰牌後不能打同牌。沒有合法可打牌的吃碰不提供按鈕。
- 自己剛打的牌，在自己再打出不同牌之前不能吃碰回來；過碰同牌須等自己出牌後才能碰。
- 過胡同巡不能點胡、自摸或搶槓，須在非胡牌狀態出牌解過水；加槓可解，暗槓不解。花胡不受過水限制。
- 剩最後三張可摸牌時不能吃、碰、明槓；暗槓／加槓仍須有可補牌。四槓與四風連打不自動流局，四槓也不自動胡牌。

## 花牌

| 目前門風 | 正花，各 1 台 |
| --- | --- |
| 東（當局莊家） | 春、梅 |
| 南 | 夏、蘭 |
| 西 | 秋、竹 |
| 北 | 冬、菊 |

湊齊四季或四君子，該組改計花槓 2 台，不再加該組正花。其他不對位的散花零台。換莊後依新門風計算。

本桌花胡採「亮花即成立」：八張全在一家為八仙過海，三家各付；七張在一家、另一張在他家為七搶一，由持單花者支付。起手全部補花完成後檢查；行牌中每次亮花立即檢查。即使第八張較早亮出，之後七加一齊備仍成立。均為 8 台，另計莊連，不疊加一般手牌、正花、花槓、自摸或補花台，不要求先完成一般胡牌結構。

同一手牌的面子拆分與胡牌落點一起計算，取合法相容的最高台組合，不能把不同拆法的平胡、暗刻任意相加。零台仍可胡，收一底。

本桌天／地聽可與門清或門清自摸相加；天／地／人胡亦可加表中未排除的相容台型。這些高階組合、字一色、全求獨聽、花牌次序及花胡時機是常見牌桌差異，已在本頁明列。

「報聽」保留為鎖手與自動摸打功能，普通報聽不加台。宣告後首張只能打成聽的合法牌；之後只能打剛摸的牌並自動胡牌。暗槓／加槓僅在等待牌種完全不變時允許；天聽、地聽不能過胡。

## 收付與換莊

每份為 `底＋台數×每台分數`。點胡／搶槓只有放槍者付一份，自摸其餘三家各付一份。莊家胡牌時牌型台數含莊連；閒家胡莊家或閒家自摸時，只有莊家另付莊連台，不重複收底。閒家之間的點胡不涉及莊連。莊家胡牌或流局連莊，閒家胡牌則換下家；起莊 1 台，每連一次再加 2 台。

例：底 2000、每台 1000，閒家 2 台點胡另一閒家，只有放槍者付 4000。莊家連二時被該閒家點胡，付 4000＋5000＝9000；不是三份。

## 存檔與參考

新版存檔包含規則版本、花牌及過水狀態，檢查 144 張實體牌的身分與唯一性。舊無花牌存檔不載入新版引擎；手動存檔不自動刪除，請重新開局。使用者主動按「儲存牌局」仍會更新同一手動存檔。
