## 共同規則

- 治療、護盾、增益與淨化只作用自己；怪物減益全員共用。
- 玩家狀態與護盾的持續時間按自己的成功出牌計算；怪物減益與持續傷害按怪物行動計算。
- 有限次效果會在次數耗盡或持續時間結束時消失。技能的「下一擊」是下一個攻擊技能，不含普攻、反擊、追擊與持續傷害。
- 所有自身治療只按實際回復量計算轉傷；吸血只按怪物實際失去的生命計算。排行榜保留過量傷害。
- 反擊與追擊不再觸發其他反擊或追擊。加槓只施放加槓技，不重播碰技；遭搶槓時不施放。
- 怪物死亡會清除其尚未觸發的狀態與印記；新怪仇恨歸零。低血量條件是生命不高於 35%。
- 比較是否最高仇恨、滿血與低血量的分支，以本招開始時狀態判斷。
- 四季、四君子每局各觸發一次。七搶一與八仙過海結算自己的終式，不重複追加一般胡牌終式。
- 補花的直接攻擊與攻擊花陣待持有者自己的回合施放，開局不替其他座位提前攻擊；支援效果立即生效。灼燒、受擊反擊保留原觸發條件。七搶一、八仙過海的結算時機及終式預算不變。

## 資料介面與驗證

- Browser：`window.MahjongCultivationSkills`；Node：`require("./cultivation-skills.js")`。
- `all`：170 筆深層凍結資料；`get(id)`：依穩定 ID 取招式；不存在回傳 `null`。
- `find(action, keyOrKeys)`：以既有牌 key 找招式。吃牌須三張連號、同花色；碰／槓可用單一牌 key，或合法完整牌組。
- `elementFor(tileKey)`：取得獨立於牌名的元素，不改任何牌 key、排序或一般模式規則。
- `details(skillOrId)`：供技能查詢與預覽使用的繁中數值陣列。
- `node --test tests/cultivation-skills.test.cjs`：檢查全部組合、數量、名稱與 ID 唯一性、效果分歧、數值上限、深層凍結及瀏覽器／Node 一致性。
- 本文件由同一技能資料生成；實際傷害、仇恨、護盾與觸發時機另由戰鬥測試驗證。
