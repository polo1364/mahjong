# 手機角色資訊與技能圖鑑驗證

日期：2026-10-25。

## 重現與修正

- 角色資訊的四項能力並排時，加成數字可能在數字中間斷行，例如`+10.4`被拆成`+1`和`0.4`。將加成完整顯示在主要數值下方，保留原有數值與顏色；套用於手機及桌機角色資訊。
- 角色頁的攜帶道具區是裝備網格中的一個子項，原先只占三分之一欄寬。改為橫跨整列，避免說明在留有大量空間時仍被擠成窄欄。
- 圖鑑入口與標題仍寫35招怪物技能，實際資料已增加為65招。改由技能資料的數量產生標示。現有圖鑑共272項：169種牌組、38項終式、65招怪物技能。
- 圖鑑的分頁、篩選、比較與牌組詳情未發現必須修改的排版問題，保留既有布局。

## 檢查範圍

`node tests/role-catalog-layout-browser.cjs`在獨立瀏覽器啟動真正的新修仙旅程，測試Chromium及WebKit的568×320、667×375、844×390、942×435、1440×900。

- 各尺寸查看玩家基本資料、進階配裝與AI隊友資訊；844×390另逐一檢查十位角色。
- 進階案例明示設定化神／2200修為、兩種三級功法、天品+10五相套裝與兩件攜帶道具，僅作顯示壓力測試，不是合法旅程取得或平衡證據。
- 從設定的修仙頁開啟圖鑑，操作下一頁、返回、動作／牌系／用途篩選、無結果搜尋、重設、三招比較、清空與規則說明。
- 每個尺寸遍歷全部23頁，檢查卡片、操作列與按鈕文字的水平溢出。第一頁與篩選／比較狀態另逐個檢查控制項捲動後的命中點、螢幕及裁切邊界；後續分頁不逐個點擊試放按鈕。
- 八花與相關花陣查閱、暗槓秘術查閱，以及技能試放預覽的關閉操作。
- 圖鑑內容可捲動到最後一張卡；減少視窗高度至844×220時仍可操作，旋轉至直式會顯示提醒，返回橫式後搜尋文字保留。

## 驗證紀錄

- 修正前376項瀏覽器檢查中，26項角色案例重現數字斷行或道具窄欄；沒有頁面例外。圖鑑分頁沒有水平溢出。
- 修正後擴充數量核對、縮小視窗及旋轉案例，共390項瀏覽器檢查通過，沒有頁面例外或HTTP錯誤回應；已檢視手機與桌機截圖。
- Node全套1,098項通過，其中包含7項圖鑑資料／搜尋測試。
- 戰鬥與結算介面回歸128項通過。
- PWA重建、91檔清單核對及24項瀏覽器檢查通過。版本以同一提交的`pwa-assets.js`為準。

本機結果與線上部署分開核對。報告和截圖存於忽略的`artifacts/`：`role-catalog-layout-report.json`、`role-catalog-before-layout.txt`、`role-catalog-unit-tests.txt`及`role-catalog-*.png`。線上複查可設定`ROLE_CATALOG_URL=https://polo1364.github.io/mahjong/`後執行相同腳本。

瀏覽器縮小視窗不等於實體手機鍵盤測試；未測實體iPhone／Android或系統工具列。本次沒有改動戰鬥數值、功法計算、裝備效果與存檔格式。
