## 2026-10-22 四家寬桌、單一設定入口與立體牌身（同日前一輪）

依已確認的結構預覽實作，桌機使用可用視窗寬高，手機依視窗調整四家區域。此節記錄同日前一輪的寬桌基底與證據，最新追加見上節；下方 2026-10-20／21 的方桌、滑動手牌、常駐側欄與底部工具列描述是歷史行為，已由寬桌版取代，數字不能合併成最新驗收總數。

### 變更範圍

- `table-scene.css` 提供寬桌與四家資訊卡；`index.html` 增加各家頭像與手牌張數顯示。四家頭像使用本地 `assets/player-portraits.png` 的四個區域，原圖與來源紀錄保留於 `art-source/player-portraits/`。
- `table-layout.js` 按實際空間安排四家手牌、副露、花牌與棄牌。自家手牌與副露共同縮放，保留同排、桌內且不水平捲動；牌背張數仍反映實際暗手，不揭露他家暗牌。桌心保留風圈、剩餘牌張與出牌提示。版型以固定視窗條件判定：寬度 ≤680px 且直向為直向版、高度 ≤550px 為矮窗版，JS 與 CSS 共用同一模式類別，避免 660×900 等臨界尺寸反覆改變桌框。一般與矮窗版的自家花牌位於自家資訊卡下方，直向版放在資訊卡右側；直向資訊卡依實際手牌頂部調整，預留輪到自己時的提示空間。
- `table-menu.js`／`.css` 將原有操作節點移入右上「設定」選單，沿用既有事件處理函式。吃、碰、槓、胡、聽、過、存讀檔、重開、聲音、規則聲光、紀錄及指南均可由此進入；有反應時入口標示「待回應」。點選手牌直接出牌。選單支援 Escape、背景點擊、Tab 焦點循環與關閉後焦點還原；開啟選單本身不暫停 AI，原遊戲設定視窗維持既有暫停行為。修正選單開啟時 AI 碰牌流程清除共用遮罩的問題，維持背景遮罩、焦點限制與可關閉操作。
- 牌身以 CSS 側邊、底座與落影呈現厚度。左右兩家暗手使用鏡像站立側視，朝向各自玩家；公開副露仍呈現可讀牌面。這是 CSS 立體效果，不是可旋轉攝影機的 WebGL 模型；晶石 PNG、無角標條件、字牌文字與原遊戲規則未改。
- `opening-animation.js` 在寬桌模式先同步版面，再從四家實際手牌區取得發牌落點；牌牆按可用寬高與控制區間距縮放。`opening-animation.css` 安排進度與跳過鈕，避免擋住落點。洗牌與遊戲繼續共用正式仙俠桌圖與桌框。

### 驗收邊界

- 手機結果為隔離 Chromium 的視窗模擬，不是實體 iOS／Android 驗收；沒有重新整理或操作使用者既有牌局。
- 小直向畫面仍受「全部同排」的寬度限制，牌面與點選空間會縮小。320×568 的 17 張手牌寬 14px，五槓時暗手 11px、副露最小約 9.45px；390×844 對應為 18px、14px、約 12.03px。1440×900 的 17 張手牌寬 63px。高解析來源不等於小尺寸下所有裝飾細節都清楚；未以放大重採樣宣稱增加解析度。
- 本輪未重跑完整多局對局、全部聲光／語音與結算排版測試；下方舊版相關證據保留，不代表新版已全部重驗。
- Node 開局 VM 未提供 IndexedDB，會輸出自動暫存的 `ReferenceError: indexedDB is not defined` 警告；18 項斷言通過，真正瀏覽器存讀檔另由 `table-menu` 驗證。
- 修改前的既有檔案保留 `*.bak.*-wide-table` 備份。

- 首次開局、下一局、重新開局、設定後重開，都經過同一個 `startNewHand` 開局入口。
- 原創動畫依序呈現洗牌、兩顆骰子、四方各 18 墩雙層牌牆、依逆時針座次拿牌。一般約 4 秒，可按「跳過動畫」或 Escape；減少動態與關閉特效約 400ms。

- 引擎一次完成發牌，動畫期間維持 `phase: 'deal'`，禁止出牌、槓牌及存檔；動畫完成後才結算可能的起手花胡並安排 AI。跳過不重新洗牌。重新開局／讀檔取消舊動畫；無效讀檔保留現局。讀檔不重播開局。
- 手機從工具頁重開會先切回牌桌。調整視窗或切入背景時快轉演出，避免留下不可操作的牌局。
- 桌框與綠色桌面皆維持 1:1，按可用視窗寬高置中。左右手牌固定垂直、鏡像排列，整手沿桌心置中；四家牌張共用 32–40px 牌寬及 5:7 比例。小方桌保留全部牌背，使用較多重疊；自己的單列手牌可滑動，操作帶在直向小畫面置於桌下、橫向或矮窗置於桌右。右欄分成牌局、指南、聲光；日誌與指南分頁，手機使用底部工具列。
- 棄牌區獨立定位於桌心四側，不受花牌或副露數量推移。桌面顯示最近的公開棄牌，點各家摘要可分頁查看全部棄牌、副露與花牌；未刪除記錄或修改 AI 的公開資訊來源。
- 四方棄牌距桌心相等。小方桌將花牌／副露預覽收納至各家的數量按鈕，避免遮住中央資訊。牌框裝飾與側席透明空白區不攔截按鈕。
