# 第二輪平衡驗證預先承諾

本檔在讀取第二輪保留組結果前寫入。第一輪正式新倍率 `[1, 0.85, 0.85, 1.1]` 的連續旅程保留組化神首試 `0/10`，仍保留為失敗證據；不得拿該十個結果調整倍率。

- 新校準：十位角色各一段不中斷的合法麻將旅程，種子 `91001 + 101 × i`，`i=0..9`，依角色目錄順序。
- 新保留組：兩個預先指定且互不重疊的十角色種子組，`101001 + 101 × i` 及 `111001 + 101 × i`，共 20 段旅程。
- 築基、金丹、元嬰試煉生命倍率固定 `1 / 0.85 / 0.85`；只校準化神。新校準組化神首試需至少 `4/10`，在不高於目前 `1.1` 的倍率中以 `0.05` 步階找最高達標倍率，並在讀取保留組結果前凍結。
- 正式驗收仍是保留組化神首試率至少 `20%`，同時核對四階與 AI／玩家平均絕對突破局差 `≤10`；報告 Wilson 95% 區間及未達標樣本。
- 若改變化神倍率，須以同一起點的合法連續後綴重跑 AI 局差與實際首試率。只在原倍率後綴從保存 checkpoint 完全重現完整旅程的結果後，才允許使用 checkpoint；否則從第一局重跑。
