# 手機修行與裝備整備驗證

日期：2026-10-25。

## 重現與修正

- 568×320 裝備內容區剩餘高度不足；即使每頁只放一張卡，固定分頁列仍會蓋住合成、購買或背包裝備。手機高度不超過560px時改用內容區捲動，保留導覽和下局準備欄；桌機沿用分頁。
- 568×320、667×375、844×390 的鑄器師強化／移轉按鈕被裁切。內容自然展開並可捲動，強化輔助欄改為各占一列，避免下拉選單擠入移轉欄。
- 移轉／分解確認框在手機整備區內獨立顯示、可捲動，避免擠壓下方內容。
- 實際切換與交易另重現：高強化裝備的保級符選項被帶到低強化裝備，觸發 `invalid-forge-item` 並卡在儲存畫面。重新進入鑄器師、執行強化或移轉時清除輔助選項；不改強化機率、費用或道具效果。
- 修行與六種功法未發現重疊，未修改其樣式或規則。

## 驗證範圍與結果

`node tests/preparation-layout-browser.cjs`：Chromium／WebKit、568×320、667×375、844×390、942×435與1440×900，共128項檢查通過，沒有頁面例外。

- 修行頁、同行養成摘要、六種功法控制項可見性；抽測第一種功法加減與保存，保存結果讀回 IndexedDB 核對。
- 本局收穫、道具行囊、配裝比較、商人、鑄器師和確認框；逐頁檢查控制項遮擋、螢幕／裁切邊界及按鈕溢出。可捲動容器允許上下捲動，沒有以捲動 `overflow:hidden` 容器掩蓋問題。
- 實際點擊穿戴、合成、購買、移轉、強化並核對狀態；驗證切換裝備及移轉後不殘留不適用的輔助符。
- 空背包、零金幣／靈砂、零道具，以及直式提醒。
- 全套 Node 1,098項通過；PWA重建、清單核對及24項瀏覽器檢查通過。

測試使用獨立瀏覽器、明示的元嬰／2200修為、裝備與材料fixture，不是自然旅程或平衡證據。已檢視手機及桌機截圖，未測實體手機。一般段落未逐字做像素邊界比對，主要操作的可見性則有幾何與命中點斷言。
