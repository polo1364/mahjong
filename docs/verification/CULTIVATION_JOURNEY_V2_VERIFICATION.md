# 修仙旅程 V2：交付與驗證紀錄

日期：2026-10-23。功能可玩；圖片解析度及部分角色平衡目標仍有下列明確差距。

## 使用方式

重新載入 `index.html`，選擇開始遊戲 → 修仙模式 → 選角。已有舊修仙存檔時可繼續舊版旅程；要使用新角色與怪物循環，選「重新開始修仙旅程」，確認後重新選角。此操作依規格清除原旅程與劫印。

新版流程：選角 → 戰鬥 → 傷害結算 → 前往整備 → 開始下一局。整備保存角色、怪物進度與下局劫印；三格裝備暫為空欄。商人、鑄器師明確標示待開放，沒有假商品、價格或無效購買按鈕。

完整圖片與能力對照：`artifacts/cultivation-journey-gallery.html`。設計契約：`docs/CULTIVATION_JOURNEY_V2_PLAN.md`。

## 驗證與修正

完整測試命令：`node --test tests/*.test.cjs`。最終修改凍結後 **800／800 通過，0 失敗、0 跳過**，耗時 36.01 秒。結果保存於 `artifacts/cultivation-journey-all-tests.txt`。獨立最後增量審查的核心／流程／VFX 73／73 通過，無剩餘已確認 P1／P2。

重點覆蓋：10 位角色、直接／持續／延遲／反擊傷害、治療與護盾轉傷上限、自然復甦、V1 相容、花牌去重、循環與失敗退階、結算／整備／讀檔、事件唯一性。

本次查出並修正：

1. 整備返回首頁的非同步保存，與開始下一局競爭時可能清掉新局；加入共同導航鎖與狀態身分檢查。
2. 長旅程第 1,001 次擊殺後紀錄上限與驗證不一致；修正並保留唯一擊殺歸屬。
3. 燃心未完整涵蓋純持傷、延遲印記與有效資源轉傷；現在整招只使用一次、基礎加傷上限 25，刷新持傷不擴大額度。
4. 怪物資訊已更新，但中央畫布仍顯示舊白虎；接上物種圖片與保持比例的完整構圖。
5. 同一張花牌擊殺後立即觸發陣法，新怪可能仍畫成舊怪；依事件的怪物身分分段，保留各段物種與既有招式計算。
6. 舊怪同時有長短招式時，新怪可能只等待最後一招短動畫；跨怪演出改為等待所有既有招式的最晚結束時間。

獨立覆核另以 1,320 組 V1 技能／AI 估算對照確認舊結果一致，1,650 組 V2 角色×技能情境加 JSON roundtrip 與後續 12 次出牌確認狀態有效。

## 平衡：組件情境與合法完整牌局分開

`tests/cultivation-journey-balance-final.json` 為 12,500 組固定種子的純戰鬥情境：5 種打法 × 10 位角色 ×（200 調整種子＋50 保留種子），輪換座位。不是瀏覽器實玩局數，技能頻率由測試策略控制。

赤綾傷害能力由 106 調為 105，其餘基礎能力依原表。相同打法下，最高與最低角色平均傷害差距如下：

| 打法 | 調整種子 | 保留種子 |
|---|---:|---:|
| 混合 | 11.16% | 10.02% |
| 爆發 | 12.23% | 12.49% |
| 治療防禦 | 10.74% | 11.11% |
| 反擊 | 13.47% | 15.03% |
| 降仇 | 11.08% | 11.35% |

**尚未在所有打法達成約 10% 目標。**反擊策略的醫修有效治療偏少，轉傷被動利用率低；保留其治療特色，沒有為了追平該策略而全面提高攻擊。樣本未見單一角色同時在傷害、生存與仇恨管理全面領先。這是有限種子與策略的結果，不代表長期平衡完成。

`tests/cultivation-journey-legal-boss-final.json` 與 `...-holdout.json` 使用實際麻將引擎／AI 在 VM 執行完整合法牌局，初始滿血 BOSS、無裝備、沒有先前怪物消耗；每 10 步驗證 144 張實體牌唯一性及戰鬥狀態。BOSS 擊殺為 **114／200（57%）**，保留種子 **28／50（56%）**。這是可重現的控制情境，並非 250 場瀏覽器或真人遊玩。

## 瀏覽器實際操作

使用獨立測試來源 `http://localhost.:8765`，沒有讀寫使用者 file:// 或 127.0.0.1 的存檔。

- 實際首頁進選角、取消、選蘇靈蘅、開局及刷新續局。續局沒有重播洗牌，生命、傷害、角色及怪物一致。
- 實際打出玄玉：傷害由 91 到 145；第四次出牌觸發霜牙狼單體攻擊，最高仇恨蘇靈蘅生命由 1,000 到 850。
- AI 打出神木後，實際明槓；「萬藤縛魔」造成 207 傷害，怪物 953 到 746，延後 1 次出牌。牌組直接點選可查看技能，查閱沒有重施放。
- 角色點選可看能力、被動及儲存加傷 0／30、本局產生 0／60。
- 桌機 1440×900、手機直向 390×844、矮橫向 844×390 檢查選角、牌桌與整備。手牌保持單排、無水平捲動；手機直向可點但牌較小。
- 整備預覽 fixture 使用正式 Combat／UI：第一局整備返回、快照續回、第二局開局與整備，角色固定、傷害歸零、未擊殺小怪原種重戰。此項是 fixture 操作，不聲稱瀏覽器完成兩場完整麻將。
- 圖鑑 35 張均成功載入；怪物／BOSS 篩選與霜牙狼名稱搜尋正確。

畫面證據位於 `artifacts/cultivation-journey-qa/`。舊測試分頁的原生確認框未能由自動化控制，該確認路徑以單元／流程測試驗證，不冒稱完整瀏覽器覆蓋。實體手機尚未驗證。
